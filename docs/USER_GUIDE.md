# User guide

## Learning modules

Choose a module from the learning hub. The demo includes plain-language concepts and a glossary, a general journey question framework, an interactive comprehension exercise, topic-level feedback, a question builder, a synthetic institutional dashboard, and accessibility settings.

The journey module deliberately leaves study-specific details empty. A real study's stages, procedures, duration, risks, benefits, and rights must be derived from its approved source documents and reviewed before being shown.

The `/learn` catalog opens the same general concepts as individual pages. `/studies/demo-study` shows the clearly labeled educational simulation, without invented clinical schedules or risks.

## Comprehension practice

The exercise checks five areas: research purpose, procedures, potential benefits, potential risks, and participant rights. It includes a scenario and an optional teach-back reflection. You can skip questions. The summary only reflects the multiple-choice/scenario answers you chose, has no pass score, and does not determine eligibility. Free-text teach-back is not automatically evaluated, saved, or sent to a server.

Use topic feedback to decide what you may want explained again. You can repeat the exercise, but repeating it is optional.

## Prepare questions

Add suggested questions or write your own. Your list stays in browser memory for this session. Choose **Print / save PDF** and then select **Save as PDF** in the browser print dialog. Printed output contains the question list.

## Accessibility

Switch between Bahasa Indonesia and English. Increase or reset text size, play browser-based narration, and turn on low-decoration mode. Audio uses the browser's speech synthesis and does not upload text. Narrated words are also shown on screen.

## Dashboard

The dashboard is a visual mockup. Every shown score is synthetic and is not a study result, user result, or evidence that SAPA-UJI improved comprehension.

## Institution workflows

Choose a persona from **Masuk demo** or the **Peran demo** selector. The selector is only for previewing role-specific pages.

- Researchers and institution admins can draft a study with a source reference, submit it for review, revise it, and publish it after approval. They can create and revise learning modules and assessment questions.
- Clinical reviewers can inspect submitted study/content/question drafts, record a note, approve, request revision, or reject. Approval in this demo is not clinical validation.
- Approved materials and questions can be published by the researcher/admin persona. Edits return the item to draft and require another review.
- Institution admins can create local invitation examples, adjust the demo institution profile, inspect the local audit timeline, and print a synthetic report.
- Super admins can add or suspend demo institutions.

Workspace state persists in this browser's `localStorage`. Reset it from **Workspace → Pengaturan → Reset data demo**. No real email is sent, and no database or API is involved.

Do not enter real participant details, personal health information, or real study content in this demo.
